# Контракт семестровой работы, версия 1

Этот документ определяет поведение обязательного API. Он имеет приоритет над упрощёнными упражнениями. Тексты сообщений исключений свободные; тип исключения и состояние после операции обязательны. Если ниже не указана обработка произвольного типа аргумента, тесты используют описанный допустимый тип.

## 1. Общие правила

| Значение | Правило |
|---|---|
| student_id | Непустая str после strip. Регистр сохраняется и влияет на уникальность. Внутренние символы не изменяются |
| name | Непустая str после очистки. Нормализация: `" ".join(name.split())`; регистр сохраняется |
| group | Непустая str после strip. Регистр и внутренние пробелы сохраняются |
| grade | Только `type(grade) is int` и `2 <= grade <= 5`. bool, float и строки отклоняются |
| grades | В конструкторе None или list. None означает новый пустой список. В файле обязательно list, даже если пустой |
| Отсутствие среднего | None; никогда не 0, строка или NaN |
| Порядок студентов | Возрастание `(student.name.casefold(), student.student_id)` средствами Python |
| Путь | str или pathlib.Path. Родительский каталог должен существовать |

Некорректные строки полей, контейнер grades и оценки дают ValueError. Никакого автоматического преобразования `"4"` или `4.0` в оценку в модели. ID при создании нормализуется strip; операции получения, удаления и добавления оценки используют переданный строковый ключ точно, без дополнительной нормализации. Интерфейс предварительно очищает введённый ID.

Атрибуты Student доступны для чтения. Прямое изменение `student_id`, `name`, `group` и списка `grades` извне не входит в поддерживаемые операции API. В частности, ID нельзя менять после добавления в журнал. Оценки добавляются через метод. Публичные проверки не требуют защиты от умышленного нарушения этой договорённости свойствами или приватными полями.

## 2. `journal.models.Student`

### `Student(student_id, name, group, grades=None)`

Проверяет и нормализует поля. Создаёт публичные атрибуты `student_id`, `name`, `group`, `grades`. Оценки сохраняются в исходном порядке. Входной список копируется; два экземпляра без оценок получают независимые списки. Неверные данные дают ValueError, объект с неверными данными не возвращается.

```python
s = Student(" S01 ", "  Анна   Иванова ", " ИС-21 ", [5, 4, 5])
assert s.student_id == "S01"
assert s.name == "Анна Иванова"
assert s.group == "ИС-21"
```

### `add_grade(grade) -> None`

Проверяет точный тип и диапазон, добавляет оценку в конец списка. При ValueError оценки остаются прежними. Порядок проверки предшествует изменению.

### `average() -> float | None`

Для непустого списка возвращает `sum(grades) / len(grades)` без округления. Для пустого — None. Входное состояние не меняется.

### `has_debt() -> bool`

True тогда и только тогда, когда среди оценок есть 2. Пустой список даёт False.

### `to_dict() -> dict`

Возвращает новый словарь с **ровно** ключами `id`, `name`, `group`, `grades`. Значение grades — новый список. Изменение результата не должно менять исходный объект.

```python
{"id": "S01", "name": "Анна Иванова", "group": "ИС-21", "grades": [5, 4, 5]}
```

### `Student.from_dict(data) -> Student`

Метод класса, вызывается без предварительного экземпляра. data — dict с ровно четырьмя перечисленными ключами. Отсутствующие и лишние поля, другой тип корня, grades=None и неверные значения дают ValueError. Создаёт независимый объект с теми же правилами нормализации, что конструктор. Словарь и его список не изменяются и не становятся общей изменяемой коллекцией с объектом.

## 3. `journal.models.GradeBook`

### `GradeBook()`

Создаёт пустой журнал. Способ внутреннего хранения свободный, словарь по ID рекомендуется. Разные журналы независимы.

### `add_student(student) -> None`

Принимает экземпляр Student. Другой тип даёт ValueError. Если такой `student.student_id` уже есть, ValueError, прежняя запись и оценки сохраняются. При успехе хранит именно переданный объект, а не копию. Разные студенты с одинаковым именем разрешены. ID `a` и `A` различны.

### `get_student(student_id) -> Student`

При строковом ID возвращает хранимый объект. Если ID нет — KeyError. Операция не создаёт запись автоматически. Возвращённый объект можно использовать для вызова его методов, но нельзя напрямую менять его ID.

### `remove_student(student_id) -> None`

Удаляет запись с точным строковым ID. Если ID нет — KeyError. Подтверждение удаления делает интерфейс до вызова, сам метод не вызывает input. Остальные записи не меняются.

### `add_grade(student_id, grade) -> None`

Сначала находит студента, затем добавляет оценку по правилам Student. Неизвестный ID — KeyError, неверная оценка существующего студента — ValueError. При любой из этих ошибок журнал не меняется.

### `list_students(group=None) -> list[Student]`

Возвращает новый внешний список хранимых объектов в порядке `(name.casefold(), student_id)`. Если group=None, включает всех. Если group — строка, требуется точное совпадение с атрибутом group. Запрос группы не нормализуется автоматически. Пустая или неизвестная группа даёт пустой список. Изменение внешнего списка результата, например clear(), не удаляет записи из журнала. Сами объекты не копируются.

### `find_students(query) -> list[Student]`

query должен быть str, иначе ValueError. Применяет strip и casefold к запросу. Пустой результат нормализации запроса даёт []. Иначе возвращает всех студентов, для которых запрос является подстрокой `name.casefold()`, в общем порядке `(name.casefold(), student_id)`. Сохраняет исходные имена и объекты. Группа в этой операции не учитывается.

### `report(group=None) -> list[dict]`

Применяет тот же фильтр и порядок, что list_students. Каждая строка — новый словарь с ровно полями:

| Поле | Тип | Значение |
|---|---|---|
| id | str | ID студента |
| name | str | Нормализованное отображаемое имя |
| group | str | Группа |
| count | int | Число оценок |
| average | float или None | Среднее без округления |
| debt | bool | Наличие хотя бы одной двойки |

Изменение словаря отчёта не меняет модель. Пустой журнал и группа без совпадений дают [].

## 4. `journal.storage.save_book(book, path) -> None`

book — корректный GradeBook, используемый только через поддерживаемые операции. Записывает UTF-8 JSON с читаемой кириллицей. Корневой объект имеет ровно `version` и `students`. version — целое число 1. students — список словарей Student.to_dict в общем порядке list_students. Форматирование пробелов и отступов свободное. Существующий файл полностью заменяется, а не дополняется.

```json
{
  "version": 1,
  "students": [
    {"id": "S01", "name": "Анна Иванова", "group": "ИС-21", "grades": [5, 4, 5]},
    {"id": "S02", "name": "Борис Петров", "group": "ИС-21", "grades": []}
  ]
}
```

Если запись невозможна, разрешите соответствующему OSError подняться вызывающему коду. Не создавайте отсутствующие родительские каталоги автоматически. Атомарная замена файла, блокировки и восстановление после аварийной записи не входят в обязательный уровень. Обработку ожидаемой ошибки и честное сообщение пользователю обеспечить нужно.

## 5. `journal.storage.load_book(path) -> GradeBook`

Читает UTF-8 JSON, проверяет схему и создаёт новый независимый журнал. Не выполняет интерактивный ввод. Обязательные отказы:

- Файл отсутствует: FileNotFoundError.
- Другая ошибка доступа/чтения: соответствующий OSError.
- Повреждённый JSON или неверная UTF-8 кодировка: ValueError (JSONDecodeError как его подкласс допустим).
- Корень не dict, отсутствуют или есть лишние корневые поля: ValueError.
- version не имеет точный тип int или не равен 1: ValueError. True и 1.0 отклоняются.
- students не list: ValueError.
- Любая неверная запись Student.from_dict: ValueError.
- Повтор ID после нормализации strip: ValueError.

Файл проверяется целиком. Нельзя возвращать частичный журнал или молча пропускать повреждённые записи. Порядок входных записей может быть любым; функции выдачи результата сортируют по общему правилу. Пустой список students допустим. При ошибке функция не возвращает новый журнал, а интерфейс сохраняет прежний.

## 6. `journal.storage.export_report(book, path, group=None) -> None`

Записывает UTF-8 CSV с разделителем `;`. Путь и ошибки записи обрабатываются так же, как в save_book. Файл открывается с newline="". Заголовок и порядок столбцов строго:

```text
id;name;group;count;average;debt
```

Источник — book.report(group), порядок строк сохраняется. count записывается десятичной строкой. average: пустая строка для None, иначе формат Python `f"{value:.2f}"` с точкой и двумя знаками. debt: `yes` для True, `no` для False. Имена с кавычками и разделителями экранируются по правилам csv. Пустой отчёт содержит только заголовок. Числа в модели не превращаются в строки при экспорте.

```text
S01;Анна Иванова;ИС-21;3;4.67;no
S02;Борис Петров;ИС-21;0;;no
```

## 7. Приоритет правил и границы

Тесты не проверяют точные тексты сообщений, оформление таблицы в консоли, внутреннее имя словаря журнала и алгоритмическую сложность. Не требуется поддержка бесконечных наборов данных, параллельных пользователей, испорченных извне атрибутов Student, нестандартных JSON-констант NaN/Infinity и повторяющихся имён ключей в сыром JSON. Требования к меню проверяются вручную по ASSIGNMENT и TESTING.

Изменение обязательного контракта преподавателем должно сопровождаться обновлением документа, тестов и номера версии. Студенты должны получить эти изменения до приёмки.
