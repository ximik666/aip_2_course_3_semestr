# Правила нормализации · пример

```python
def normalize_name(text):
    return " ".join(text.split())
```

# Сравнение без учёта регистра

Подстрока может совпасть с частью слова

Пустой запрос обрабатывается отдельно

# Сравнение без учёта регистра · пример

```python
def find_names(names, query):
    query = query.strip().casefold()
    if not query:
        return []
    return [name for name in names if query in name.casefold()]

print(find_names(["Анна", "Борис", "Антон"], " АН "))
print(find_names(["Анна"], " "))
```

# Выделение слов

Слово определяется явным правилом

Разделители заменяются пробелами

Формы одного слова пока считаются отдельно

---

# Выделение слов · пример

```python
def tokenize(text):
    chars = []
    for char in text.casefold():
        chars.append(char if char.isalpha() else " ")
    return "".join(chars).split()

print(tokenize("Кот,пёс! КОТ-2."))
```

# Частотный словарь

Ключом является подготовленное слово

Счётчик начинается с нуля

Общее количество и число уникальных слов различаются

---

# Частотный словарь · пример

```python
def frequencies(words):
    counts = {}
    for word in words:
        counts[word] = counts.get(word, 0) + 1
    return counts

words = ["кот", "кот", "пёс"]
counts = frequencies(words)
print(counts)
print(len(words), len(counts))
```

# Топ слов и устойчивое правило порядка

Первый ключ задаёт убывание частоты

Второй ключ разрешает равенство частот

Нулевой и отрицательный лимит дают пустой список

---

# Топ слов и устойчивое правило порядка · пример

```python
def top_words(counts, limit):
    if limit <= 0:
        return []
    pairs = sorted(counts.items(), key=lambda pair: (-pair[1], pair[0]))
    return pairs[:limit]

print(top_words({"пёс": 2, "кот": 3, "дом": 2}, 2))
```

# Удаление дублей с сохранением порядка

Множество хранит уже встреченные ключи

Список сохраняет порядок первых появлений

Дубль текста не означает одного и того же человека

---

# Удаление дублей с сохранением порядка · пример

```python
def unique_names(names):
    result, seen = [], set()
    for raw in names:
        name = " ".join(raw.split())
        key = name.casefold()
        if name and key not in seen:
            seen.add(key)
            result.append(name)
    return result

print(unique_names([" Анна ", "Борис", "АННА", ""]))
```

# Последовательность обработки и проверка · пример

```python
def normalize_name(text):
    return " ".join(text.split())

cases = [("  Анна   Иванова ", "Анна Иванова"),
         ("\t\n", ""), ("Борис", "Борис")]
for source, expected in cases:
    assert normalize_name(source) == expected
print("Проверка нормализации завершена")
```
