# Запись как словарь

Одна запись содержит поля с именами

Схема должна быть одинаковой у всех записей

get применяется к необязательным полям

---

# Запись как словарь · пример

```python
student = {"id": "S01", "name": "Анна",
           "group": "ИС-21", "grades": [4, 5]}
print(student["name"])
print(student.get("email", "не указан"))
student["grades"].append(3)
print(student["grades"])
```

# Словарь записей по ID

ID не зависит от имени студента

Присваивание существующему ключу заменяет запись

Добавление требует проверки дубликата

---

# Словарь записей по ID · пример

```python
def add_record(book, record):
    key = record["id"]
    if key in book:
        return False
    book[key] = record
    return True

book = {}
print(add_record(book, {"id": "S01", "name": "Анна"}))
print(add_record(book, {"id": "S01", "name": "Борис"}))
print(book["S01"]["name"])
```

# Поиск и фильтрация

Фильтрация создаёт список подходящих записей

Пустой список означает отсутствие совпадений

Правило сравнения строк задаётся явно

---

# Поиск и фильтрация · пример

```python
def select_group(students, group):
    result = []
    for student in students:
        if student["group"] == group:
            result.append(student)
    return result

rows = [{"name": "Анна", "group": "A"},
        {"name": "Борис", "group": "B"}]
print(select_group(rows, "A"))
```

# Изменение и удаление записи

Изменяется конкретное поле найденной записи

Сначала собираются ключи для массового удаления

Подтверждение пользователя относится к интерфейсу

---

# Изменение и удаление записи · пример

```python
book = {"1": {"name": "Анна", "group": "A"},
        "2": {"name": "Борис", "group": "B"}}
book["1"]["group"] = "B"
keys = [key for key in book if book[key]["name"] == "Борис"]
for key in keys:
    del book[key]
print(book)
```

# Группировка и подсчёт

Ключ группировки выбирается по задаче

Первое появление ключа требует начального значения

Счётчик и список решают разные задачи

---

# Группировка и подсчёт · пример

```python
students = [{"name": "Анна", "group": "A"},
            {"name": "Борис", "group": "B"},
            {"name": "Вера", "group": "A"}]
counts = {}
for student in students:
    group = student["group"]
    counts[group] = counts.get(group, 0) + 1
print(counts)
```

# Поверхностная копия и вложенные списки

copy не копирует вложенные объекты

Независимость проверяется после изменения копии

Известную схему можно скопировать явно

---

# Поверхностная копия и вложенные списки · пример

```python
original = {"id": "1", "grades": [4, 5]}
copied = {"id": original["id"],
          "grades": original["grades"].copy()}
copied["grades"].append(2)
print(original)
print(copied)
```

# Упорядоченный отчёт

sorted создаёт новый список

key задаёт правило сравнения

Второй ключ разрешает совпадения первого

---

# Упорядоченный отчёт · пример

```python
rows = [{"id": "2", "name": "анна"},
        {"id": "1", "name": "Анна"},
        {"id": "3", "name": "Борис"}]
ordered = sorted(rows, key=lambda row: (row["name"].casefold(), row["id"]))
print([row["id"] for row in ordered])
```
