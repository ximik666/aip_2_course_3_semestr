# Цикл команд · пример

```python
for command in ["3", "x", "0"]:
    if command == "0":
        print("Выход")
        break
    elif command == "3":
        print("Отчёт пока пуст")
    else:
        print("Неизвестная команда")
```

# Несохранённые изменения

Успешное изменение устанавливает changed=True

Успешное сохранение сбрасывает флаг

Ошибка сохранения оставляет изменения несохранёнными

---

# Несохранённые изменения · пример

```python
changed = False
grades = []
grades.append(5)
changed = True
print("Есть изменения:", changed)
# Предположим, функция сохранения завершилась успешно.
changed = False
print("После сохранения:", changed)
```

# Безопасная замена при загрузке

Загрузка сначала создаёт новый объект

Присваивание выполняется после успешной проверки

Ошибка не заменяет текущие данные

---

# Безопасная замена при загрузке · пример

```python
book = ["Анна"]

def load_invalid():
    raise ValueError("Повреждённый файл")

try:
    loaded = load_invalid()
    book = loaded
except ValueError:
    print("Загрузка отменена")
print(book)
```
