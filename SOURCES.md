# Справочники и происхождение материала

План продолжает [темы первого курса](https://github.com/ximik666/aip_1_course). Основание выбора уровня — опубликованный README репозитория и сообщение преподавателя о прохождении материала; полного аудита всех прежних заданий не заявляется.

Курс использует стабильные возможности Python, доступные в 3.11+. Объяснения и демонстрационные задачи написаны специально для этого комплекта. Документация помогает уточнять поведение стандартных средств:

- [Функции](https://docs.python.org/3/tutorial/controlflow.html#defining-functions)
- [Коллекции](https://docs.python.org/3/tutorial/datastructures.html)
- [Строки и словари](https://docs.python.org/3/library/stdtypes.html)
- [JSON](https://docs.python.org/3/library/json.html)
- [CSV](https://docs.python.org/3/library/csv.html)
- [Исключения](https://docs.python.org/3/tutorial/errors.html)
- [unittest](https://docs.python.org/3/library/unittest.html)
- [Классы](https://docs.python.org/3/tutorial/classes.html)
- [Модули](https://docs.python.org/3/tutorial/modules.html)
- [pathlib](https://docs.python.org/3/library/pathlib.html)
- [tempfile](https://docs.python.org/3/library/tempfile.html)

Ссылки без номера версии открывают текущую документацию Python. Для фиксированного справочника можно заменить `/3/` на `/3.11/`. Фактическая локальная проверка комплекта описана в CHECKS.md.
