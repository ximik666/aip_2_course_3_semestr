# Практическое занятие 4. Фильтрация и группировка записей

**Продолжительность:** 90 минут. **Основной уровень:** обязательный для всех. Дополнительное задание выполняется после базовой части.

## Цель

Сформировать несколько представлений одних данных без изменения исходных записей.

## Подготовка и исходные материалы

Прочитайте [лекцию 2](../../lectures/02/README.md). Нужны Python 3.11+, текстовый редактор и терминал. Внешние библиотеки не используются.

В каталоге занятия лежат [starter.py](starter.py), [tests.py](tests.py) и [check.py](check.py). Стартовый файл содержит имена функций и методов, которые ожидают тесты. Заготовка намеренно не проходит проверки до реализации.

Из корня курса один раз подготовьте каталог своей работы и скопируйте заготовку:

```bash
python -c "from pathlib import Path; import shutil; p=Path('student_work/p04'); p.mkdir(parents=True, exist_ok=True); t=p/'solution.py'; assert not t.exists(), 'Решение уже существует'; shutil.copyfile('practices/04/starter.py', t)"
```

Если файл уже существует, продолжайте работу в нём. Не копируйте заготовку поверх своего решения. Команда содержит защитную учебную проверку и запускается без флага `-O`.

## Пошаговая работа

### Задание 1. `select_group(records, group)`

**Контракт.** Возвращает новый список записей с точным совпадением group в исходном порядке. Элементы можно не копировать. Нет совпадений — [].

**Пример результата.** Для групп A, B, A фильтр A возвращает первую и третью запись.

**Порядок выполнения:**

1. Выпишите допустимые входы и тип результата.
2. Рассчитайте результат примера вручную и запишите его рядом с решением.
3. Реализуйте функцию или методы в `solution.py`, сохранив указанные имена.
4. Проверьте пример и один отличающийся случай. Объясните, меняет ли операция входные данные.

**Подсказка при затруднении.** Отделите внешний новый список от вложенных общих словарей.

### Задание 2. `count_by_group(records)`

**Контракт.** Возвращает словарь группа → количество студентов. Пустой вход даёт {}. Каждая запись учитывается ровно один раз.

**Пример результата.** Группы ["A", "B", "A"] дают {"A":2, "B":1}.

**Порядок выполнения:**

1. Выпишите допустимые входы и тип результата.
2. Рассчитайте результат примера вручную и запишите его рядом с решением.
3. Реализуйте функцию или методы в `solution.py`, сохранив указанные имена.
4. Проверьте пример и один отличающийся случай. Объясните, меняет ли операция входные данные.

**Подсказка при затруднении.** Используйте get(group, 0) перед увеличением.

### Задание 3. `sort_records(records)`

**Контракт.** Возвращает новый список, упорядоченный по (name.casefold(), id). ID сравнивается как строка. Исходный порядок входа не меняется.

**Пример результата.** Имена «анна» с ID 2 и «Анна» с ID 1 идут в порядке ID 1, 2.

**Порядок выполнения:**

1. Выпишите допустимые входы и тип результата.
2. Рассчитайте результат примера вручную и запишите его рядом с решением.
3. Реализуйте функцию или методы в `solution.py`, сохранив указанные имена.
4. Проверьте пример и один отличающийся случай. Объясните, меняет ли операция входные данные.

**Подсказка при затруднении.** В sorted передайте функцию key, возвращающую кортеж.

## Самопроверка

Из корня курса:

```bash
python practices/04/check.py --solution student_work/p04/solution.py
```

Ожидается `OK`. `FAIL` означает неверный результат проверки, `ERROR` — непредусмотренное исключение. Смотрите имя теста и последнюю строку сообщения. Исправляйте реализацию, а не публичные тесты.

Добавьте минимум три собственных примера, которых нет в таблицах задания. Запишите вход, ожидаемый результат и фактический результат. Для изменяемых коллекций проверьте состояние до и после вызова. На практиках 1–9 достаточно отдельного `self_check.py` с assert; начиная с практики 10 используйте unittest.

## Типичные ошибки

Перезапись счётчика единицей на каждой итерации; сортировка входа через sort; случайное сравнение групп без учёта согласованного регистра.

## Что сдать

- `solution.py` с реализованными функциями или классами.
- Собственные проверки и таблицу минимум из трёх случаев в `README.md`.
- Короткое объяснение алгоритма: какие шаги выполняются и почему выбран такой результат для пустого входа.
- Результат запуска проверок: команда, число выполненных тестов, итог. Снимок экрана не обязателен.
