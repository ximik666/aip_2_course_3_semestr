# Практическая работа «Выдача книг в библиотеке»

**Время:** 90 минут.  
**Тема:** словари, списки и обработка заявок.

## Условие

В библиотеке есть несколько книг. Читатели подают заявки на получение книги. Программа должна проверять наличие свободных экземпляров, учитывать выданные книги и формировать отчёт.

Все данные задаются в программе. Ввод с клавиатуры и работа с файлами не требуются.

```python
# Код книги и название

available = {

readers = {
    "Анна": [],

}

# Заявки: имя читателя и код книги
requests = [
```

Один читатель может получить **не более двух разных книг**. Повторно выдавать ему ту же книгу нельзя.

## Часть 1. Обработка заявок

Обрабатывайте заявки по порядку. Для каждой заявки проверяйте:

1. Зарегистрирован ли читатель.
2. Существует ли книга.
3. Нет ли уже этой книги у читателя.
4. Получил ли читатель меньше двух книг.
5. Есть ли свободный экземпляр.

Если все условия выполнены:

- добавьте код книги в список читателя;
- уменьшите количество свободных экземпляров на один.

Если хотя бы одно условие нарушено, ничего не меняйте и выведите причину отказа. Проверки выполняйте в указанном порядке.

Примеры сообщений:

```text
Анна: выдана книга «Основы Python»
Анна: эта книга уже получена
Глеб: свободных экземпляров нет
Анна: уже получены две книги
```

## Часть 2. Отчёт по читателям

Для каждого зарегистрированного читателя выведите:

- имя;
- названия полученных книг;
- количество книг на руках.

Пример:

```text
Анна
Книги: Основы Python, Базы данных
Всего книг: 2
```

Если список пуст, выводите «Книг на руках нет».

## Часть 3. Поиск читателей каждой книги

На основе словаря `readers` создайте новый словарь `book_readers`.

Ключ — код книги, значение — список читателей, которым она выдана.

Пример:


В словаре должны присутствовать все книги, включая те, которые никто не получил. Порядок имён не важен.

## Часть 4. Статистика

Определите и выведите:

1. Общее количество выданных экземпляров.
2. Количество читателей, получивших хотя бы одну книгу.
3. Названия книг, свободных экземпляров которых не осталось.
4. Имена читателей, получивших ровно две книги.

## Обязательные проверки

Каждую проверку запускайте с исходными остатками и пустыми списками читателей.

- Заявок нет — остатки не меняются.
- Одна корректная заявка — книга добавляется читателю, остаток уменьшается на один.
- Повторная заявка на ту же книгу — отказ без изменения остатка.
- Заявка на третью книгу — отказ.
- Неизвестный читатель или книга — сообщение об ошибке, программа продолжает работу.
- Последний экземпляр успешно выдаётся, следующая заявка отклоняется.

## Подсказки

- `name in readers` — проверка регистрации читателя.
- `code in books` — проверка существования книги.
- `code in readers[name]` — проверка повторной выдачи.
- `len(readers[name])` — количество книг у читателя.
- `readers[name].append(code)` — добавление книги.

Названия книг получайте из `books` по коду. Не дублируйте названия во всех рабочих словарях.
