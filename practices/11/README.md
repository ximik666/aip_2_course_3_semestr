В каталоге занятия лежат [starter.py](starter.py), [tests.py](tests.py) и [check.py](check.py). Стартовый файл содержит имена функций и методов, которые ожидают тесты. Заготовка намеренно не проходит проверки до реализации.


Если файл уже существует, продолжайте работу в нём. Не копируйте заготовку поверх своего решения. Команда содержит защитную учебную проверку и запускается без флага `-O`.

## Пошаговая работа

### Задание 1. `Student(name, grades=None)`

**Контракт.** Создаёт атрибуты name и grades. name — непустая str после очистки пробелов. grades — None или список точных int 2–5. Ошибки дают ValueError. Список копируется. В этой практике ещё нет ID и группы.

**Пример результата.** Student("  Анна   Иванова ", [4]).name == "Анна Иванова".

**Порядок выполнения:**

1. Выпишите допустимые входы и тип результата.
2. Рассчитайте результат примера вручную и запишите его рядом с решением.
3. Реализуйте функцию или методы в `solution.py`, сохранив указанные имена.
4. Проверьте пример и один отличающийся случай. Объясните, меняет ли операция входные данные.

**Подсказка при затруднении.** Создайте индивидуальный список в __init__; повторно используйте add_grade.

### Задание 2. `Student.add_grade(grade), Student.average()`

**Контракт.** Добавление проверяет точный int 2–5, изменяет список, возвращает None; при ValueError список прежний. average возвращает среднее без округления либо None.

**Пример результата.** Student("А", [4,5]).average() == 4.5.

**Порядок выполнения:**

1. Выпишите допустимые входы и тип результата.
2. Рассчитайте результат примера вручную и запишите его рядом с решением.
3. Реализуйте функцию или методы в `solution.py`, сохранив указанные имена.
4. Проверьте пример и один отличающийся случай. Объясните, меняет ли операция входные данные.

**Подсказка при затруднении.** Метод обращается к self.grades.

### Задание 3. `Student.to_dict()`

**Контракт.** Возвращает словарь с ровно name и grades. Возвращаемый список grades независим от объекта.

**Пример результата.** Изменение student.to_dict()["grades"] не меняет student.grades.

**Порядок выполнения:**

1. Выпишите допустимые входы и тип результата.
2. Рассчитайте результат примера вручную и запишите его рядом с решением.
3. Реализуйте функцию или методы в `solution.py`, сохранив указанные имена.
4. Проверьте пример и один отличающийся случай. Объясните, меняет ли операция входные данные.

**Подсказка при затруднении.** Копируйте вложенный список, а не только словарь.

## Самопроверка

Из корня курса:

```bash
python practices/11/check.py --solution student_work/p11/solution.py
```

Ожидается `OK`. `FAIL` означает неверный результат проверки, `ERROR` — непредусмотренное исключение. Смотрите имя теста и последнюю строку сообщения. Исправляйте реализацию, а не публичные тесты.

Добавьте минимум три собственных примера, которых нет в таблицах задания. Запишите вход, ожидаемый результат и фактический результат. Для изменяемых коллекций проверьте состояние до и после вызова. На практиках 1–9 достаточно отдельного `self_check.py` с assert; начиная с практики 10 используйте unittest.

## Типичные ошибки

grades на уровне класса; [] в параметре по умолчанию; забытый self; словарь экспорта делит список с объектом.
