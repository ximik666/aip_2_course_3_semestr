# Практическая работа «Запись на факультативы»

**Время:** 90 минут.  
**Тема:** словари и списки в Python.

## Условие

В университете открылись три факультатива. На каждом ограничено количество мест.

Напишите программу, которая обрабатывает заявки студентов, записывает их при наличии свободных мест и выводит итоговый отчёт.

Все данные задаются в программе. Ввод с клавиатуры и работа с файлами не требуются.

## Исходные данные

```python
# Код факультатива и его название
courses = {
    "PY": "Python",
    "WEB": "Веб-разработка",
    "DATA": "Анализ данных",
}

# Максимальное количество участников
limits = {
    "PY": 3,
    "WEB": 2,
    "DATA": 2,
}

# Текущие участники
participants = {
    "PY": [],
    "WEB": [],
    "DATA": [],
}

# Заявки: имя студента и код факультатива
applications = [
    ("Анна", "PY"),
    ("Борис", "WEB"),
    ("Вера", "PY"),
    ("Анна", "PY"),
    ("Глеб", "DATA"),
    ("Дина", "PY"),
    ("Егор", "PY"),
    ("Анна", "WEB"),
    ("Вера", "WEB"),
    ("Борис", "DATA"),
    ("Дина", "DATA"),
    ("Глеб", "DESIGN"),
]
```

В рамках задачи считайте, что одинаковое имя обозначает одного студента. Все имена записаны без ошибок.

## Часть 1. Обработка заявок

Обработайте заявки по порядку.

Для каждой заявки:

1. Проверьте, существует ли факультатив.
2. Если существует, проверьте, не записан ли студент на него ранее.
3. Если студент ещё не записан, проверьте наличие свободных мест.
4. Если место есть, добавьте имя в список участников.

Один студент может посещать несколько разных факультативов.

После каждой заявки выводите сообщение, например:

```text
Анна: записана на Python
Анна: уже записана на Python
Егор: на Python нет свободных мест
Глеб: факультатив DESIGN не найден
```

Точная формулировка сообщения может отличаться. Главное — правильно указать результат.

**Важно:** при повторной заявке выводите «уже записан», даже если факультатив заполнен.

## Часть 2. Отчёт по факультативам

После обработки всех заявок выведите для каждого факультатива:

- название;
- имена участников;
- количество участников;
- количество свободных мест.

Пример оформления:

```text
Python
Участники: Анна, Вера, Дина
Занято мест: 3 из 3
Свободно мест: 0
```

Если участников нет, выводите «Пока никто не записан».

## Часть 3. Словарь студентов

На основе словаря `participants` создайте новый словарь:

```python
student_courses = {
    "Анна": ["PY", "WEB"],
    "Вера": ["PY"],
    "Дина": ["PY"],
    "Борис": ["WEB", "DATA"],
    "Глеб": ["DATA"],
}
```

Ключ — имя студента, значение — список факультативов, на которые он успешно записан.

Не добавляйте сюда студентов, которым отказали во всех заявках. Порядок ключей и факультативов не важен.

Выведите сведения в понятном виде:

```text
Анна: Python, Веб-разработка
Борис: Веб-разработка, Анализ данных
```

## Часть 4. Краткая статистика

Определите:

1. Сколько уникальных студентов записано хотя бы на один факультатив.
2. Сколько всего занятых мест на всех факультативах.
3. Какие студенты записаны более чем на один факультатив.

Обратите внимание: один студент может занимать место на двух факультативах, поэтому количество студентов и количество занятых мест могут различаться.

## Ожидаемый результат

Итоговый словарь участников:

```python
{
    "PY": ["Анна", "Вера", "Дина"],
    "WEB": ["Борис", "Анна"],
    "DATA": ["Глеб", "Борис"],
}
```

Статистика:

```text
Уникальных студентов: 5
Всего занятых мест: 7
На нескольких факультативах: Анна, Борис
```

Порядок имён в последней строке может отличаться.

## Как проверить программу

Перед каждой независимой проверкой создавайте новый словарь с пустыми списками участников.

Проверьте следующие случаи:

- **Заявок нет:** участников нет, все места свободны.
- **Одна заявка:** студент добавляется на выбранный факультатив.
- **Повторная заявка:** имя не появляется в списке дважды.
- **Мест не осталось:** новый студент не добавляется.
- **Неизвестный код:** программа сообщает об ошибке и продолжает обработку следующих заявок.

## Подсказки

- `key in dictionary` проверяет наличие ключа в словаре.
- `name in participants[code]` проверяет наличие имени в списке.
- `len(participants[code])` возвращает количество участников.
- `.append(name)` добавляет имя в список.
- `.items()` позволяет перебирать ключи и значения словаря.

При создании `student_courses` сначала проверяйте наличие имени. Если имя встретилось впервые, создайте для него пустой список, затем добавьте код факультатива.
