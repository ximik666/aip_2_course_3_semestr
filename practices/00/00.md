## Задание 1. Анализ последовательности — 20 минут

Напишите функцию `analyze_numbers(numbers)`, принимающую список целых чисел.

Функция должна вернуть кортеж из четырёх значений:

1. Второй по величине **различный** элемент списка. Если различных значений меньше двух — `None`.
2. Количество пар соседних элементов с противоположными знаками. Ноль не считается ни положительным, ни отрицательным.
3. Длину самой длинной непрерывной строго возрастающей последовательности.
4. Список без повторений с сохранением порядка первого появления элементов.

**Ограничения:** не используйте `set()`, `sorted()`, `.sort()`, `max()` и `min()`.

Пример:

```python
analyze_numbers([3, -2, 0, 4, 4, -1, 5, 2])
```

Результат:

```python
(4, 3, 3, [3, -2, 0, 4, -1, 5, 2])
```

Пояснения:

- Наибольший элемент — `5`, второй различный — `4`.
- Знак меняется в парах `(3, -2)`, `(4, -1)`, `(-1, 5)`.
- Самый длинный возрастающий фрагмент — `[-2, 0, 4]`.

Граничные случаи:

```python
analyze_numbers([])       # (None, 0, 0, [])
analyze_numbers([7, 7])   # (None, 0, 1, [7])
```

## Задание 2. Анализ текста — 20 минут

Напишите функцию `analyze_text(text)`, которая анализирует строку и возвращает список пар:

```python
[(слово, количество_повторений), ...]
```

Правила обработки:

- Регистр букв не учитывается.
- Словом считается непрерывная последовательность букв.
- Цифры, пробелы и знаки препинания разделяют слова.
- Слова в результате располагаются по убыванию количества повторений.
- При одинаковом количестве повторений сохраняется порядок первого появления слов в тексте.

**Ограничения:** не используйте регулярные выражения, `collections.Counter`, `sorted()` и `.sort()`. Для определения букв можно использовать `.isalpha()`. Сортировку реализуйте самостоятельно.

Пример:

```python
analyze_text("Код, тест! Код и тест. Python — код.")
```

Результат:

```python
[("код", 3), ("тест", 2), ("и", 1), ("python", 1)]
```

Другие случаи:

```python
analyze_text("кот123пёс кот")
# [("кот", 2), ("пёс", 1)]

analyze_text("123...!?")
# []
```

**Объясните:** что нужно сделать, чтобы последнее слово не потерялось, если строка заканчивается буквой?

## Задание 3. Проверка скобок с помощью стека — 20 минут

Напишите функцию `check_brackets(text)` для проверки правильности расстановки скобок `()`, `[]`, `{}`.

Используйте список как стек. Все символы, кроме скобок, игнорируются.

Функция возвращает:

- `(True, -1)`, если скобки расставлены правильно;
- `(False, индекс)`, если найдена ошибка.

Правила определения индекса ошибки:

1. Если закрывающей скобке не соответствует последняя открывающая — верните индекс этой закрывающей скобки.
2. Если после просмотра всей строки остались незакрытые скобки — верните индекс **самой ранней из оставшихся незакрытых** открывающих скобок.

Индексы начинаются с нуля и относятся к исходной строке.

Примеры:

```python
check_brackets("a * (b + [c - 2])")
# (True, -1)

check_brackets("([)]")
# (False, 2)

check_brackets("abc]")
# (False, 3)

check_brackets("a(b[c]")
# (False, 1)

check_brackets("")
# (True, -1)
```

**Объясните:** почему одинаковое количество открывающих и закрывающих скобок ещё не означает правильность выражения?

## Задание 4. Исправление бинарного поиска — 15 минут

Следующая функция должна находить индекс **первого вхождения** числа в отсортированном по возрастанию списке. Если числа нет, требуется вернуть `-1`.

Однако в программе есть ошибки:

```python
def binary_search_first(numbers, target):
    left = 0
    right = len(numbers)

    while left < right:
        middle = (left + right) // 2

        if numbers[middle] == target:
            return middle
        elif numbers[middle] < target:
            left = middle
        else:
            right = middle - 1

    return -1
```

Выполните следующие действия:

1. Найдите ошибки в границах и изменении диапазона поиска.
2. Приведите пример, на котором исходная функция зацикливается.
3. Приведите пример, на котором она пропускает существующий элемент.
4. Исправьте функцию, сохранив бинарный поиск.
5. Обеспечьте поиск первого вхождения при повторяющихся значениях.

Проверки:

```python
binary_search_first([1, 2, 2, 2, 5], 2)  # 1
binary_search_first([1, 2, 2, 2, 5], 1)  # 0
binary_search_first([1, 2, 2, 2, 5], 5)  # 4
binary_search_first([1, 2, 2, 2, 5], 3)  # -1
binary_search_first([7], 7)              # 0
binary_search_first([], 7)               # -1
```

**Ограничения:** нельзя использовать `.index()`, линейный перебор или проход влево по всем одинаковым элементам после обнаружения совпадения.

## Задание 5. Седловые точки матрицы — 10 минут

Напишите функцию `saddle_points(matrix)`.

**Седловая точка** в этой задаче — элемент, который одновременно:

- является минимальным в своей строке;
- является максимальным в своём столбце.

Функция возвращает список кортежей:

```python
(индекс_строки, индекс_столбца, значение)
```

Если подходящих элементов несколько, включите все — в порядке обхода по строкам слева направо. Равенство значений допускается.

Пример:

```python
saddle_points([
    [3, 1, 3],
    [4, 2, 5],
    [2, 0, 4]
])
```

Результат:

```python
[(1, 1, 2)]
```

Другие случаи:

```python
saddle_points([[5, 5], [5, 5]])
# [(0, 0, 5), (0, 1, 5), (1, 0, 5), (1, 1, 5)]

saddle_points([])
# []

saddle_points([[], []])
# []
```

Можно считать, что передана прямоугольная матрица целых чисел. Используйте вложенные циклы; не используйте `min()` и `max()`.
