# Практическое занятие 5. Анализатор текста

**Продолжительность:** 90 минут. **Основной уровень:** обязательный для всех. Дополнительное задание выполняется после базовой части.

## Цель

Получить частотный отчёт из текста по явно заданным правилам выделения слов.

## Подготовка и исходные материалы

Прочитайте [лекцию 3](../../lectures/03/README.md). Нужны Python 3.11+, текстовый редактор и терминал. Внешние библиотеки не используются.

В каталоге занятия лежат [starter.py](starter.py), [tests.py](tests.py) и [check.py](check.py). Стартовый файл содержит имена функций и методов, которые ожидают тесты. Заготовка намеренно не проходит проверки до реализации.

Из корня курса один раз подготовьте каталог своей работы и скопируйте заготовку:

```bash
python -c "from pathlib import Path; import shutil; p=Path('student_work/p05'); p.mkdir(parents=True, exist_ok=True); t=p/'solution.py'; assert not t.exists(), 'Решение уже существует'; shutil.copyfile('practices/05/starter.py', t)"
```

Если файл уже существует, продолжайте работу в нём. Не копируйте заготовку поверх своего решения. Команда содержит защитную учебную проверку и запускается без флага `-O`.

## Пошаговая работа

### Задание 1. `tokenize(text)`

**Контракт.** Принимает строку. Сначала casefold. Слово — непрерывная последовательность символов isalpha(). Все остальные символы заменяются пробелами. Возвращает список слов. Дефис разделяет слова, цифры не входят в слова, ё сохраняется.

**Пример результата.** tokenize("Кот,пёс! КОТ-2.") == ["кот", "пёс", "кот"].

**Порядок выполнения:**

1. Выпишите допустимые входы и тип результата.
2. Рассчитайте результат примера вручную и запишите его рядом с решением.
3. Реализуйте функцию или методы в `solution.py`, сохранив указанные имена.
4. Проверьте пример и один отличающийся случай. Объясните, меняет ли операция входные данные.

**Подсказка при затруднении.** Не удаляйте разделители без замены: соседние слова могут склеиться.

### Задание 2. `frequencies(words)`

**Контракт.** Принимает список готовых слов и возвращает словарь частот. Нормализацию повторно не выполняет. Пустой список даёт {}.

**Пример результата.** frequencies(["кот", "кот", "пёс"]) == {"кот":2, "пёс":1}.

**Порядок выполнения:**

1. Выпишите допустимые входы и тип результата.
2. Рассчитайте результат примера вручную и запишите его рядом с решением.
3. Реализуйте функцию или методы в `solution.py`, сохранив указанные имена.
4. Проверьте пример и один отличающийся случай. Объясните, меняет ли операция входные данные.

**Подсказка при затруднении.** Каждое слово увеличивает ровно один счётчик.

### Задание 3. `top_words(counts, limit)`

**Контракт.** Возвращает список пар (слово, частота), сначала по убыванию частоты, затем по слову. limit — целое число; при limit <= 0 возвращает []. Лимит больше числа слов допустим.

**Пример результата.** top_words({"б":2, "а":2, "в":3}, 2) == [("в",3), ("а",2)].

**Порядок выполнения:**

1. Выпишите допустимые входы и тип результата.
2. Рассчитайте результат примера вручную и запишите его рядом с решением.
3. Реализуйте функцию или методы в `solution.py`, сохранив указанные имена.
4. Проверьте пример и один отличающийся случай. Объясните, меняет ли операция входные данные.

**Подсказка при затруднении.** Ключ сортировки: отрицательная частота и слово.

## Самопроверка

Из корня курса:

```bash
python practices/05/check.py --solution student_work/p05/solution.py
```

Ожидается `OK`. `FAIL` означает неверный результат проверки, `ERROR` — непредусмотренное исключение. Смотрите имя теста и последнюю строку сообщения. Исправляйте реализацию, а не публичные тесты.

Добавьте минимум три собственных примера, которых нет в таблицах задания. Запишите вход, ожидаемый результат и фактический результат. Для изменяемых коллекций проверьте состояние до и после вызова. На практиках 1–9 достаточно отдельного `self_check.py` с assert; начиная с практики 10 используйте unittest.

## Типичные ошибки

Удаление запятой склеивает слова; повторный подсчёт по всему списку; обратная сортировка разворачивает и алфавитный порядок при равенстве.

## Что сдать

- `solution.py` с реализованными функциями или классами.
- Собственные проверки и таблицу минимум из трёх случаев в `README.md`.
- Короткое объяснение алгоритма: какие шаги выполняются и почему выбран такой результат для пустого входа.
- Результат запуска проверок: команда, число выполненных тестов, итог. Снимок экрана не обязателен.
