# Практическое занятие 13. Сборка семестрового приложения

**Продолжительность:** 90 минут. Это этап семестровой работы, отдельные баллы за обычную практику не начисляются: результат учитывается по рубрике проекта.

## Цель

Соединить ранее подготовленные Student, GradeBook, хранение и меню. К концу пары должны работать основной сквозной сценарий и публичные проверки. Класс и хранение предполагаются подготовленными по этапам семестра; написать весь проект с нуля за одну пару не является целью.

## До занятия

Прочитайте [лекцию 7](../../lectures/07/README.md), [задание](../../semester/ASSIGNMENT.md), [контракт](../../semester/SPECIFICATION.md) и [инструкцию тестирования](../../semester/TESTING.md). Подготовьте копию semester/starter в semester/submission. Если вы уже работаете в submission, повторно копировать заготовку нельзя.

Принесите готовые методы модели и прототипы сохранения/загрузки из предыдущих практик. Сравните их с итоговыми сигнатурами: упрощённый GradeBook.add из практики 12 нужно адаптировать к add_student, а сортировку по ID — к сортировке по имени и ID.

## Задание 1. Проверка модели

Из корня курса:

```bash
python semester/run_tests.py --solution semester/submission --pattern test_models.py
```

Разделите ошибки по методам. Сначала исправьте конструктор и add_grade, затем методы журнала. Не меняйте ожидаемые значения в тестах. Проверьте, что Student с пустыми оценками даёт None, bool не принимается как оценка, повтор ID не заменяет существующую запись. Объясните один исправленный дефект преподавателю.

## Задание 2. Проверка файлов

```bash
python semester/run_tests.py --solution semester/submission --pattern test_storage.py
```

Проверьте загрузку [demo.json](../../semester/data/demo.json) и сравните экспорт с [expected_report.csv](../../semester/data/expected_report.csv). Ошибки CSV удобно искать, читая строки через csv.reader. Для JSON сравнивайте структуру, а не отступы. Убедитесь, что после ошибки повреждённого файла функция не возвращает частичный журнал.

## Задание 3. Сквозной сценарий

Из каталога semester/submission выполните `python -m journal`.

1. Добавьте S01, «Анна Иванова», ИС-21.
2. Добавьте оценки 5, 4, 5. Отчёт показывает 3 оценки, 4.67, отсутствие двоек.
3. Добавьте S02, «Борис Петров», ИС-21, затем оценку 2. В отчёте есть долг.
4. Сохраните JSON в свой рабочий файл, завершите программу, запустите снова и загрузите его.
5. Проверьте, что оба студента и все оценки восстановлены.
6. Экспортируйте CSV; проверьте заголовок, две строки и два знака среднего.

## Задание 4. Ошибка без потери состояния

Внесите новое изменение, затем попробуйте загрузить broken.json. Отмена подтверждения должна сохранить прежние данные. При подтверждении и ошибке чтения прежние данные тоже должны остаться. Введите вместо оценки «пять» и затем 6. Программа должна сообщить об ошибке и продолжить работу.

Добавьте собственный тест на взаимодействие нескольких операций, например сохранение после удаления или повторное сохранение после изменения оценки. Ожидаемый результат запишите до запуска.
