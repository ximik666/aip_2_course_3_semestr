# Практическое занятие 6. Очистка имён и поиск дублей

**Продолжительность:** 90 минут. **Основной уровень:** обязательный для всех. Дополнительное задание выполняется после базовой части.

## Цель

Привести текстовые данные к согласованному виду и сохранить порядок первых появлений.

## Подготовка и исходные материалы

Прочитайте [лекцию 3](../../lectures/03/README.md). Нужны Python 3.11+, текстовый редактор и терминал. Внешние библиотеки не используются.

В каталоге занятия лежат [starter.py](starter.py), [tests.py](tests.py) и [check.py](check.py). Стартовый файл содержит имена функций и методов, которые ожидают тесты. Заготовка намеренно не проходит проверки до реализации.

Из корня курса один раз подготовьте каталог своей работы и скопируйте заготовку:

```bash
python -c "from pathlib import Path; import shutil; p=Path('student_work/p06'); p.mkdir(parents=True, exist_ok=True); t=p/'solution.py'; assert not t.exists(), 'Решение уже существует'; shutil.copyfile('practices/06/starter.py', t)"
```

Если файл уже существует, продолжайте работу в нём. Не копируйте заготовку поверх своего решения. Команда содержит защитную учебную проверку и запускается без флага `-O`.

## Пошаговая работа

### Задание 1. `normalize_name(text)`

**Контракт.** Возвращает строку с одним пробелом между словами и без краевых пробелов. Регистр сохраняется. Любые пробельные символы обрабатываются split без аргумента.

**Пример результата.** normalize_name("  Анна\t Иванова ") == "Анна Иванова".

**Порядок выполнения:**

1. Выпишите допустимые входы и тип результата.
2. Рассчитайте результат примера вручную и запишите его рядом с решением.
3. Реализуйте функцию или методы в `solution.py`, сохранив указанные имена.
4. Проверьте пример и один отличающийся случай. Объясните, меняет ли операция входные данные.

**Подсказка при затруднении.** Соедините результат split через один пробел.

### Задание 2. `unique_names(names)`

**Контракт.** Нормализует каждую строку, пропускает пустые имена, удаляет дубли по casefold. Сохраняет порядок и регистр первого нормализованного появления. Вход не меняет.

**Пример результата.** unique_names([" Анна ", "АННА", "Борис", " "]) == ["Анна", "Борис"].

**Порядок выполнения:**

1. Выпишите допустимые входы и тип результата.
2. Рассчитайте результат примера вручную и запишите его рядом с решением.
3. Реализуйте функцию или методы в `solution.py`, сохранив указанные имена.
4. Проверьте пример и один отличающийся случай. Объясните, меняет ли операция входные данные.

**Подсказка при затруднении.** Храните ключи в seen, отображаемые строки — в result.

### Задание 3. `find_names(names, query)`

**Контракт.** names — уже подготовленные строки. query обрабатывается strip и casefold. Возвращает все совпадения подстроки в исходном порядке, сохраняя исходные строки. Пустой запрос даёт [].

**Пример результата.** find_names(["Анна", "Антон", "Борис"], " АН ") == ["Анна", "Антон"].

**Порядок выполнения:**

1. Выпишите допустимые входы и тип результата.
2. Рассчитайте результат примера вручную и запишите его рядом с решением.
3. Реализуйте функцию или методы в `solution.py`, сохранив указанные имена.
4. Проверьте пример и один отличающийся случай. Объясните, меняет ли операция входные данные.

**Подсказка при затруднении.** Пустоту проверяйте до оператора in.

## Самопроверка

Из корня курса:

```bash
python practices/06/check.py --solution student_work/p06/solution.py
```

Ожидается `OK`. `FAIL` означает неверный результат проверки, `ERROR` — непредусмотренное исключение. Смотрите имя теста и последнюю строку сообщения. Исправляйте реализацию, а не публичные тесты.

Добавьте минимум три собственных примера, которых нет в таблицах задания. Запишите вход, ожидаемый результат и фактический результат. Для изменяемых коллекций проверьте состояние до и после вызова. На практиках 1–9 достаточно отдельного `self_check.py` с assert; начиная с практики 10 используйте unittest.

## Типичные ошибки

title меняет исходное оформление; set теряет требуемый порядок; пустой запрос возвращает все записи.
