# Практическое занятие 8. CSV: импорт оценок и экспорт отчёта

**Продолжительность:** 90 минут. **Основной уровень:** обязательный для всех. Дополнительное задание выполняется после базовой части.

## Цель

Прочитать табличные строки, преобразовать типы и сформировать отчёт с корректным экранированием.

## Подготовка и исходные материалы

Прочитайте [лекцию 4](../../lectures/04/README.md). Нужны Python 3.11+, текстовый редактор и терминал. Внешние библиотеки не используются.

В каталоге занятия лежат [starter.py](starter.py), [tests.py](tests.py) и [check.py](check.py). Стартовый файл содержит имена функций и методов, которые ожидают тесты. Заготовка намеренно не проходит проверки до реализации.

Из корня курса один раз подготовьте каталог своей работы и скопируйте заготовку:

```bash
python -c "from pathlib import Path; import shutil; p=Path('student_work/p08'); p.mkdir(parents=True, exist_ok=True); t=p/'solution.py'; assert not t.exists(), 'Решение уже существует'; shutil.copyfile('practices/08/starter.py', t)"
```

Если файл уже существует, продолжайте работу в нём. Не копируйте заготовку поверх своего решения. Команда содержит защитную учебную проверку и запускается без флага `-O`.

## Пошаговая работа

### Задание 1. `read_grades(path)`

**Контракт.** Читает UTF-8 CSV с разделителем ; и точным заголовком name;grade. Возвращает список словарей name (строка), grade (int). Для этой практики строки корректны, оценки 2–5. Пустая таблица с заголовком даёт [].

**Пример результата.** Строка «Анна;5» становится {"name":"Анна", "grade":5}.

**Порядок выполнения:**

1. Выпишите допустимые входы и тип результата.
2. Рассчитайте результат примера вручную и запишите его рядом с решением.
3. Реализуйте функцию или методы в `solution.py`, сохранив указанные имена.
4. Проверьте пример и один отличающийся случай. Объясните, меняет ли операция входные данные.

**Подсказка при затруднении.** Используйте DictReader, затем int для столбца grade.

### Задание 2. `summarize_rows(rows)`

**Контракт.** Группирует корректные строки по точному name. Возвращает словари name, count, average, отсортированные по строке name. Среднее не округляется. Пустой вход даёт [].

**Пример результата.** Две строки Анна с 4 и 5 дают {"name":"Анна", "count":2, "average":4.5}.

**Порядок выполнения:**

1. Выпишите допустимые входы и тип результата.
2. Рассчитайте результат примера вручную и запишите его рядом с решением.
3. Реализуйте функцию или методы в `solution.py`, сохранив указанные имена.
4. Проверьте пример и один отличающийся случай. Объясните, меняет ли операция входные данные.

**Подсказка при затруднении.** Накопите оценки по именам. В этом упражнении совпадающие имена намеренно объединяются.

### Задание 3. `write_summary(rows, path)`

**Контракт.** rows — результат summarize_rows. Пишет UTF-8 CSV с ;, заголовок name;count;average и среднее с двумя знаками. Порядок rows сохраняется. Кавычки и разделители в имени экранируются модулем csv. Возвращает None.

**Пример результата.** Анна;2;4.50. Для пустого rows остаётся заголовок.

**Порядок выполнения:**

1. Выпишите допустимые входы и тип результата.
2. Рассчитайте результат примера вручную и запишите его рядом с решением.
3. Реализуйте функцию или методы в `solution.py`, сохранив указанные имена.
4. Проверьте пример и один отличающийся случай. Объясните, меняет ли операция входные данные.

**Подсказка при затруднении.** Файл открывается с newline="". Передайте фиксированный fieldnames.

## Самопроверка

Из корня курса:

```bash
python practices/08/check.py --solution student_work/p08/solution.py
```

Ожидается `OK`. `FAIL` означает неверный результат проверки, `ERROR` — непредусмотренное исключение. Смотрите имя теста и последнюю строку сообщения. Исправляйте реализацию, а не публичные тесты.

Добавьте минимум три собственных примера, которых нет в таблицах задания. Запишите вход, ожидаемый результат и фактический результат. Для изменяемых коллекций проверьте состояние до и после вызова. На практиках 1–9 достаточно отдельного `self_check.py` с assert; начиная с практики 10 используйте unittest.

## Типичные ошибки

split вместо csv; сложение строковых оценок; группировка по имени перенесена в журнал, где нужен ID; изменение числового среднего при экспорте.
