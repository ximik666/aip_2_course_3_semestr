# Проверка комплекта

Дата: 9 сентября 2026 года. Проверка выполнена локально на macOS.

## Код и структура

- 49 демонстрационных программ выполнены; вывод совпал с ожидаемым.
- 48 тестовых методов практик 1–12 прошли на преподавательских решениях.
- 46 публичных тестовых методов семестровой работы прошли на эталоне.
- 8 дополнительных тестов эталона прошли.
- Проверены синтаксис Python, наличие обязательных файлов и локальные ссылки учебного репозитория.
- Эти проверки пройдены на Python 3.12.14 и 3.14.6. Минимальная заявленная версия — 3.11; отдельно на 3.11 комплект не запускался.
- Заготовка проекта и намеренно ошибочная программа практики 10 отклоняются тестами: их ошибки ожидаемы до выполнения задания.

## Проверка качества тестов

В эталон по одному внесены восемь ошибок: ноль вместо отсутствующего среднего, преждевременное округление, допуск оценки 6, неверное определение задолженности, общий список оценок при экспорте словаря, неверная сортировка, поиск с учётом регистра и неверный разделитель CSV. Публичные тесты обнаружили каждую ошибку.

Два сценария консольного интерфейса проверили создание, оценки, ошибки ввода, поиск, отмену удаления, сохранение и повторную загрузку, CSV, отказ от потери несохранённых данных, повреждённый файл, удаление и сохранение пустого журнала. Импорт модулей не запускает меню.

Это не доказательство отсутствия всех ошибок. При защите выполняются ручные сценарии из `semester/TESTING.md` и обсуждение кода.

## Презентации

Все семь PPTX содержат по 17 слайдов: всего 119. Проверка структуры пакета, компоновки, шрифтов и повторного импорта пройдена. Все слайды итоговых PPTX отрисованы и просмотрены: обрезания текста и перекрытия не обнаружены. Проверка выполнена средствами генерации и рендеринга презентаций; запуск в настольном PowerPoint не выполнялся.

В HTML проверены структура и число слайдов. Визуальная проверка HTML и клавиатурного управления в браузере не выполнена: доступный браузерный движок не запустился. Перед показом HTML откройте нужный файл в браузере аудитории; для основного показа также доступны проверенные PPTX.

## Повторение проверок

Из корня учебного репозитория:

```bash
python tools/check_materials.py
```

Проверки решений запускаются по инструкции преподавательского комплекта. Публичный репозиторий содержит задания и заготовки, поэтому прохождение тестов незавершёнными заготовками не ожидается. GitHub Actions подготовлены, но удалённый запуск не выполнялся.
