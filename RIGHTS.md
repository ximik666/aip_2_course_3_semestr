# Права и использование

Комплект подготовлен по запросу преподавателя для редактирования и публикации учебных материалов. Имя правообладателя и конкретная открытая лицензия не назначены автоматически. Перед публичным распространением владелец репозитория может добавить LICENSE с выбранными условиями.

Материалы первого курса использовались как ориентир уже пройденных тем. Файлы и тексты исходного репозитория в комплект не копировались. Официальная документация Python указана как справочник; код демонстраций и задания написаны для этого курса. Логотипы, фотографии и сторонние иллюстрации не использованы.
