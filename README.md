# Алгоритмизация и программирование · 2 курс · Python

Готовый прикладной курс: **7 лекций, 7 презентаций, 14 практических занятий и семестровая работа с автоматической проверкой**. Материалы на русском языке. Основная среда — Python 3.11+ и стандартная библиотека, без обязательных внешних пакетов.

Курс рассчитан на студентов, знакомых с переменными, условиями, циклами, строками, списками, функциями, файлами, поиском, сортировками, стеками и очередями. Он продолжает [программу первого курса](https://github.com/ximik666/aip_1_course), но использует собственные новые объяснения, примеры и задания. Предполагается, что каждое занятие занимает 90 минут.

## Начало работы

1. Установите или выберите Python 3.11+. Проверьте `python --version`.
2. Откройте конспект нужной лекции и соответствующие практики из таблицы ниже.
3. Для практики скопируйте заготовку в свой рабочий каталог и выполните команды из задания.
4. Семестровую работу начните с [задания](semester/ASSIGNMENT.md), затем изучите [контракт](semester/SPECIFICATION.md) и [тестирование](semester/TESTING.md).

В macOS/Linux вместо `python` может требоваться `python3`, в Windows — `py -3`. Команды в заданиях выполняются из корня курса, если явно не указан другой каталог. Интернет для запуска учебного кода и тестов не нужен.

В каждой лекции: результаты обучения, сценарий пары, подробное объяснение, семь запускаемых примеров с ожидаемым выводом, вопросы и самостоятельная работа. PowerPoint-версии редактируемые.

Практики 1–12 содержат стартовый код и публичные проверки, практики 13–14 — сборку и защиту семестрового проекта. Незавершённые заготовки намеренно не проходят проверки: студент реализует их по контракту.

## Преподавателю

Читайте [руководство курса](COURSE_GUIDE.md), [календарный план](SYLLABUS.md) и [заметки по публикации](PUBLISHING.md). Эталон проекта, решения практик и ключи лекций поставляются отдельным комплектом `aip_2_course_teacher`. Они намеренно отсутствуют в этом студенческом репозитории. Заметки внутри презентаций содержат ответы на лекционные вопросы, но не решения самостоятельных практик и семестровой работы.

## Проверка репозитория

```bash
python tools/check_materials.py
```

Команда проверяет структуру, локальные ссылки, синтаксис Python, вывод демонстраций и наличие презентаций. Она **не считает заготовки выполненными** и не запускает их как готовые решения. GitHub Actions повторяет эту проверку для Python 3.11 и 3.12. Для проверяемого студенческого решения есть отдельный запускаемый вручную workflow.
